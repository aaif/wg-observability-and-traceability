# [Report] Observability & Traceability – August 2026

**Working Group:** WG Observability & Traceability

**Reporting period:** August 2026

**Chair(s):** Pavan Sudheendra (Cisco) & Matthew Lee (Datadog)

**Date submitted:** 2026-08-31

---

## Summary

In August, the WG confirmed the initial scope of the Agent Behavior Trace Model and outlined a reference implementation and test plan. We also expanded cross-boundary observability proposals, contributed O&T terms to the shared AAIF taxonomy, and published survey, use-case, and working-methods updates. Matthew Lee will lead the trace-model work and coordinate implementation throughout September.

## Progress Against Objectives

- **Agent Behavior Trace Model.** The proposal uses portable telemetry context to preserve execution context and causal relationships across agents, SDKs, gateways, and telemetry backends. Portable context supports the behavior model; it is not a separate model or a replacement for OpenTelemetry GenAI. The implementation plan combines a reference library, synthetic examples, and conformance tests to identify gaps that warrant OTel GenAI contributions. Review covered canonical identifiers, multi-agent context reuse, long-running tasks, privacy, verifiable evidence, and linking plans and decisions to execution and outcomes without requiring raw chain-of-thought capture.

- **Cross-boundary observability.** Developed initial metadata mappings for agent-to-skill, skill-to-tool, agent-to-agent, and agent-to-MCP interactions. The draft gap model and detailed MCP-server and local CLI proposals are open for GitHub review. Possible follow-ups include context propagation guidance or extensions, reference instrumentation, and a conformance checklist.

- **Published work.** Merged the Working Methods document and contributor checklist, the full-stack tracing landscape survey, and an updated prior-work survey. Added use cases for cross-surface identity resolution and tamper-evident evidence for audits and dispute resolution.

- **O&T taxonomy contributions.** Seven terms were accepted for inclusion at the August 17 review: Reasoning, Agent Trajectory, Context Propagation, Memory Access, Context Assembly, Retrieval, and Traceability. Definitions still need final review and publication. Cross-WG discussions addressed overlapping uses of Delegation and Handoff; Responsibility Chain, Side Effect, and Provenance Ledger remain under discussion.

- **Cross-WG collaboration and participation.** Identified Workflow & Process Integration reference architectures as potential test cases for the trace model. Agreed to open focus-group invitations to the full WG.

## Blockers and Risks

- Initial trace-model scope is agreed, but full implementation has not yet begun. Most of September will be spent on implementation and validation. Contributor and reviewer availability remain risks to the October recommendations.
- The cross-boundary observability work still needs a confirmed lead.

None.

## Next Month's Focus

1. Build and test the trace-model reference library within the agreed scope. Use end-to-end examples to test correlation across independently instrumented components and distinguish missing guidance from gaps in existing standards.
2. Review the cross-boundary model and MCP-server and local CLI proposals, and confirm ownership of follow-up work.
3. Submit definition PRs for the seven accepted O&T taxonomy terms. Resolve overlapping definitions and maintenance responsibilities with the relevant WGs.
