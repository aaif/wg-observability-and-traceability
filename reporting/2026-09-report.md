**Chair(s):** Pavan Sudheendra (Cisco) & Matthew Lee (Datadog)

## Summary

In September, the WG published all seven accepted Observability & Traceability terms to the shared AAIF taxonomy, merged the Agent Behavior Trace Model execution plan, published an Agent-to-Tool local CLI boundary analysis, and opened an upstream ARD lifecycle-observability proposal backed by implementation evidence. The State, Context & Reasoning focus group also began recruiting contributors and scoping candidate deliverables around state-space representation and harness-independent state inference. The trace-model work is currently under review, we are refining the plan and break down the remaining tasks for October.

- **Agent Behavior Trace Model.** Merged the execution plan and created eight follow-on issues covering baselines, the shared contract, tests, implementation, independent interpretation, runnable examples, and upstream contributions.

- **AAIF taxonomy (leads: Joe Maionchi and Pavan)** Merged definitions for Reasoning, Agent Trajectory, Context Propagation, Context Assembly, Memory Access, Retrieval, and Traceability into the shared Taxonomy & Landscape repository. Four additional terms were proposed and was approved for future inclusion.

- **Cross-boundary observability.** Published the first filled Agent-to-Tool matrix pass using a local CLI realization. The analysis maps OpenTelemetry GenAI and CLI spans, W3C Trace Context and Baggage, process context propagation, lifecycle, outcomes, provenance, security, and timing. The core cross-boundary model, the Agent-to-MCP analysis, and additional runtime/HITL rows remain under review.

- **LLM Primitives & Protocols (leads: Matthew Khouzam and Zayne Turner) - ARD lifecycle observability.** Opened an upstream ARD specification issue proposing non-normative guidance to correlate discovery, federation, trust-evidence verification, resource selection, policy decisions, and native-protocol handoff using W3C Trace Context. The proposal is backed by a Registry and MCP client prototype spanning ARD REST, Registry, Agent Gateway, a policy processor, and the selected MCP server. The experiment identified an external policy-processing boundary that required explicit context forwarding and showed that a rejected resource produced decision evidence without downstream invocation. The guidance remains under discussion and has not been adopted by ARD. Also, began gathering interested contributors and scoping other possible focus-group deliverables.

- **State, Context & Reasoning (lead: Govindaraj).** Began gathering interested contributors and scoping possible focus-group deliverables. Candidate directions include a concrete agent state-space representation; a lightweight state-inference layer for custom harnesses; observable models for tasks, goals, steps, subagents, skills, post-inference behavior, and multi-agent topologies; and an evaluation of whether inferred state improves verification or evaluation quality enough to justify its cost. Deliverable scope, owners, and validation criteria are not yet agreed and are being discussed.

- **Landscape and use cases.** Updated the prior-work survey with A2A as an AAIF-hosted interoperability project and refreshed the prior-work and use-case documents to use organization-neutral language.

- **Scope and coordination.** The WG agreed to include lower-layer observability within the Primitives & Protocol Observability focus area, with Trace leading the provenance effort. The group also reviewed Agent Action Capsule as a possible worked example for verifiable action evidence and approved adding a monthly APAC/APJ synchronization meeting. These are reported meeting outcomes; implementation artifacts have not yet been published.
